# Profiling And Exploratory Analysis

This directory contains the project's main exploratory notebooks and literate analysis files.

## Conventions

- Use `.Rmd` for reproducible R analysis. Use `.ipynb` for interactive Python when it is the better fit.
- Document every code chunk or cell: purpose, inputs, outputs, and important assumptions.
- Record random seeds, runtime/package details, and enough metadata to regenerate important outputs.
- Maintain an authorship and touch history in every analysis file, naming each human or AI agent that changed it, the date, and the nature of the change.
- Distinguish historical execution evidence (backfill) from a verified rerun. Never imply that code was rerun when only prior results were documented.
